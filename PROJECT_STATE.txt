KNOWN LIMITATIONS / CAUTION
- Scanned pages have no selectable text; OCR is not implemented.
- Text replacement rebuilds affected pages as high-resolution page images with the original covered before the new text is painted, so original text is removed from that exported page's content stream. A replaced page is flattened; links, forms, and selectable text on that page may be lost. White covers can look wrong on colored/patterned backgrounds.
- Existing embedded PDF fonts cannot always be reused. Export approximates with standard PDF fonts, so exact appearance is not guaranteed.
- Many annotations/text are flattened when exported. Verify form fields/links and image export details in src/lib/pdfEngine.js before extending.
- Do not claim full Adobe/Sejda parity.

Export now copies all pages natively using pdf-lib (output.copyPages), preserving 100% of the original vector curves, fonts, sharpness, and metadata. Text replacements now draw an opaque vector rectangle over the old text coordinates and draw crisp vector text using standard PDF fonts at the exact baseline.
- Fixed Text Run Grouping: `readTextRuns()` now groups adjacent and space-separated text items sharing the same baseline and font into coherent phrases/lines instead of fragmented individual words or letters.
- Fixed Inline Text Editor Zoom Bug: In `PdfPage.jsx`, inline editor inputs and save checkmarks were using unzoomed offsets on a zoomed canvas; their positions and dimensions are now correctly multiplied by `zoom` so the input box stays aligned with text at any zoom level.
- Added Paper Background Sampling: `sampleBackgroundColor()` samples the canvas background behind text so replacement masks blend with paper tone instead of forcing plain #ffffff.
- Fixed Typography & Color Drift: Added `resolveFontFamily()` with safe standard CSS chains so Canvas never fails and resets to 10px default font. Added luminance-sorted contrast sampling in `sampleTextColor()` to extract the exact text ink color without color shifts or rounding steps. Saved exact text baseline offsets (`baselineOffset`) so edited text stays on the original baseline down to the pixel.
- Added Direct Click-to-Edit & Modern Interaction: Eliminated the need to switch back and forth between "Select" and "Edit text" tools. Users can now directly click any text run or text mark to edit it immediately in place, click any image to select/move/resize with 4 corner handles, double-click empty canvas to add a new text box, and enjoy dynamic hover cursors (I-beam text cursor over text, move/resize cursor over images).
- Integrated @pdf-lib/fontkit: Registered fontkit in `src/lib/pdfEngine.js` for custom TrueType/OpenType font embedding support in PDF-lib.
- Integrated Tesseract.js Client-Side OCR: Created `src/lib/ocrEngine.js` with WebAssembly OCR. Users can click "OCR Page" in the toolbar to automatically recognize text coordinates and words on scanned/image-based documents, converting them into editable text runs.
- Modern Iconography & UI (`lucide-react`): Upgraded all toolbar controls, tools, and header buttons with sleek vector Lucide icons.
- Fixed Typography Ink Bleed & Grey Washout: Solved bug where edited text (such as "New York City" line) faded to grey (#858585). `sampleTextColor()` now extracts true ink strokes (`lum <= Math.min(160, minLum + 40)`) without averaging white paper pixels, and clamps standard document dark ink (< 90 RGB) to solid crisp black `#111111`. `active.originalColor` preserves the sampled color during inline editing so re-sampling never dilutes ink. `PdfPage.jsx` explicitly sets `context.textBaseline = 'alphabetic'` and renders crisp solid `#111111`.

Removed conflicting duplicate pointerdown/click event dispatching in `PdfPage.jsx`. Typing a signature in the dialog now immediately inserts it onto the active page ready to be positioned, preventing duplicate signatures on subsequent clicks.
- Fixed Photo / Image Insert: `loadImage()` now accepts all image formats (`image/*`, PNG, JPG, WebP, GIF, SVG), auto-converts via offscreen canvas to PNG for guaranteed PDF-lib vector embedding, and immediately places the photo onto the current page with 4-corner resize handles and direct drag-to-move.
